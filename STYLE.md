# SF-in-Lean Style Guide

Conventions for how the SFL material itself should be written, structured, and
read. `CONTRIBUTING.md` covers *workflow and mechanics*; this file is about
*style*.

This is a work in progress: the sections below are placeholders, to be filled
in as we settle conventions. The plan to eventually make these normative and
**checkable** is sketched in [STYLE-CHECKING.md](STYLE-CHECKING.md).
